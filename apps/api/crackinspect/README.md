# crackinspect package

| Folder | Responsibility |
|--------|----------------|
| `core/` | Shared config / paths |
| `detection/` | Scene routing, crack masks, overlays, analyze pipeline |
| `enhancement/` | Image sharpen / deblur helpers |
| `vlm/` | Ollama client, captions, structure, reports, chat |
| `geo/` | EXIF + reverse geocoding |
| `lidar/` | LAS viewers, map overlay, 3D scene helpers |
| `domain/` | Condition assessment schemas |
| `agents/` | Multi-agent condition workflow |
